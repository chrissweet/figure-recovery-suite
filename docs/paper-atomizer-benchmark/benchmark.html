Read it fairly

OWID is the clean read. Independent published ground truth, tied to neither tool — the honest headline. There the suite leads paper-atomizer by a wide margin.

aedes is self-referential. Its ground truth is paper-atomizer's own human-curated output, so paper-atomizer's automatic run is graded against a corrected version of itself. Useful as an auto-vs-curated signal, not a clean face-off.

The scorer under-counts every tool. The raw per-series matcher zeros correct points when a tool labels a series differently than the GT (e.g. aedes el-60-b: colours vs "Series 1/2/3" → all points scored FN despite ~1% coordinate agreement — this hits every tool), mis-routes some multi-series charts, and can't parse categorical bar labels. The eight charts set aside from the headline are exactly these structural mis-scores, applied identically to all three tools: synthetic 02/05/08, owid life-exp-vs-gdp / global-primary-energy / population / annual-co2, aedes el-60-b. Every one extracted real data; the scorer, not the extraction, lost the points.
